这个机械臂实际上来自于本科时参加一个科技竞赛时和队友一同自主设计搭建的小车上的机械臂，由4个旋转关节和1个移动关节构成，比赛时的任务就是抓物料和码垛物料，因此它是码垛机器人的变体

整个机械臂共 5 个自由度，无法到达空间中任意的位置和姿态 (6D Pose)，因此末端位姿可以看作是：
- 末端位置 $(x,y,z)$
- 末端俯仰角 $(\phi, \omega)$；
即少了 $\text{Roll}$ 这个欧拉角；

通常 $ZYX$ 类型的欧拉角包含：$(\text{Roll}, \text{Pitch}, \text{Yaw})$，在这个机械臂中，$\text{Roll}$ 值只能取 $0$ 或 $-180°$，从正运动学时的示教器可以看出这一点

### 运动学逆解-解析法

第5个关节是一个夹爪，看作棱柱关节，先不参与求解；
于是问题分为两部分：平面定位 $(q1)$ 和平面内构型 $(q_2,q_3,q_4)$
运动学参数：
1. 基座高度： $d_1=0.08525$
2. 手腕侧向偏移：$d_4=0.04039$
3. 大臂长度：$a_2=0.12893$
4. 小臂长度：$a_3=0.129$
5. 夹爪末端伸长：$L_{tool}=q_5+0.07403$

<u>求解</u>

1.求解基座关节 $q_1$;

关节1负责调整机械臂的朝向，由于存在侧向偏移 $d_4$，机械臂去够某个点 $(x, y)$ 的时候，存在一个偏置角度，设==末端==在==基坐标系==下的位置为 $(x,y)$，则水平距离为 $r_{xy}=\sqrt{x^2+y^2}$，
由于 $d_4$ 的存在，末端手腕的平面不过原点，而是与基座平分面平行，且与原点距离为 $d_4$ 的平面；
基座的旋转有下面两种情况：

![[b281f41ed72dd9316aa63c6b10c1cd07.jpg]]

不论是哪一种，都满足（取右手的情况）：
$$\theta_1 = \text{Atan2}(y,x)$$
$$\theta_2= \text{arcsin}(\frac{d_4}{x^2+y^2})$$
$$q_1=\theta_1+\theta_2$$
此处应该注意，需满足 $r_{xy}=\sqrt{x^2+y^2}>d_4$ 否则末端位置无法到达；

2.投影到手臂平面（基座平分面）

将末端坐标 $(x,y,z)$，转换到由 $(q_2,q_3)$ 构成的竖直平面内，才能方便计算 $(q_2,q_3,q_4)$，在该竖直平面内的，末端的坐标为 $(r,z_{plane})$:
其中，
$r$ 为径向距离，即末端投影到水平面后，沿着手臂到基座中心的距离，由于 $d_4$ 是垂直于平面的，平面内的有效伸展距离为：
$$r = \sqrt{x^2 + y^2 - d_4^2}$$
$z_{plane}$ 为 $q_2$ 关节坐标系中心相对于地面的高度：
$$z_{plane} = z - d_1$$

3.求解平面关节 $q_2, q_3, q_4$

之后，$q_2, q_3, q_4$ 就变成了平面的三连杆问题，定义俯仰角 $\phi$（末端相对于水平面的夹角），末端执行器 $O_5$ 的位置是由 $O_4$ 的中心加上长度 $L_{tool}$ 沿着 $Z_5$ 方向延伸得到，且 $\alpha_4 = -90^\circ$，因此 $Z_5$ 正方向的方向向量在这个竖直平面内，且方向由 $q_2+q_3+q_4$ 决定，因此俯仰角 $\phi=q_2+q_3+q_4$

![[baefa1526218876895b614ecbd02f54d.jpg]]

平面三连杆存在二解，通常取==肘部上凸==的构型（即图中蓝色部分）

先将工具末端平面坐标 $(r, z_{plane})$ 转换到手腕中心在平面内的坐标  $(r_{w}, z_{w})$：
$$r_{w} = r - L_{tool} \cdot \cos(\phi)$$
$$z_{w} = z_{plane} - L_{tool} \cdot \sin(\phi)$$

之后通过几何法求解 $q_2, q_3$（两杆逆解，类似余弦定理）：
$$\text{cos}\theta_3 = \frac{r_{w}^2 + z_{w}^2 - a_2^2 - a_3^2}{2 a_2 a_3}$$
则有：
$$q_3 = \pm \text{acos}(\theta_3)$$
其中：
$$q_3 = \text{arccos}(\theta_3) \quad \text{(“肘部上凸”构型)}$$
$$q_3 = -\text{acos}(\theta_3) \quad \text{(“肘部下凸”构型)}$$

继续求 $q_2$：
$$\theta_2 = \text{Atan2}(z_\omega,r_\omega)$$
$$\theta_1 = \text{Atan2}(a_3\text{sin}(q_3), a_2+a_3\text{cos}(-q_3))$$
$$q_2=\theta_2+\theta_1  \quad \text{(“肘部上凸”构型)}$$
$$q_2=\theta_2-\theta_1  \quad \text{(“肘部下凸”构型)}$$

最后求解 $q_4$，由于总的俯仰角 $\phi$ 是所有关节角的累加（需要考虑 offset），关节 $O_2$ 的 $\text{offset}=\pi/2$，关节 $O_4$ 的 $\text{offset}=-\pi/2$，于是最终全局角度关系为：
$$\phi = (q_2 + \frac{\pi}{2}) + q_3 + (q_4 - \frac{\pi}{2}) = q_2 + q_3 + q_4$$
因此可得：
$$q_4 = \phi - q_2 - q_3$$
这里的 $\phi$ 是末端连杆相对于水平面的绝对角度，和欧拉角中的 $\text{Pitch}$ 不完全等价，需要进行一定的变换，具体可参考后文的代码部分，此外由于肩部关节在定义的时候存在一个 $\pi/2$ 的正偏置，在关节空间中 $q_2=0$ 的时候在上文的解析运算的值是 $pi/2$，因此在返回 $q_2$ 时需减去 $\pi/2$ 的偏置值，这一点也可以参考后文的代码，而 $q_4$ 的偏置无需处理，因为求解出来的角度零轴刚好沿着机械臂展延伸方向

最终完整实现了从末端工作空间坐标 $(x,y,z,\phi)$ 到关节空间坐标 $(q_1,q_2,q_3,q_4)$ 的转换（$L_{tool}$ 视为已知，因为机械臂末端是一个舵机控制的夹爪，方便起见认为只有开和闭两种状态，两种状态下对应的长度已知）

### 仿真验证

对于 $ZYX$ 类型的欧拉角
此机械臂 roll = 0 或 -pi，pitch 为-90°~90°
roll = 0 时，说明头朝上，phi = 90° - pitch 
roll = -pi时，说明头朝下，phi = pitch - 90°

逆运动学的Python仿真代码如下：
```python
import numpy as np
import roboticstoolbox as rtb
from roboticstoolbox.robot.DHLink import RevoluteMDH, PrismaticMDH
from roboticstoolbox import DHRobot
import math
from spatialmath import SE3
  
L1 = RevoluteMDH(d=0.08525,   a=0.0,        alpha=0.0,        offset=0.0)
L2 = RevoluteMDH(d=0.0,       a=0.0,        alpha=np.pi/2,    offset=np.pi/2)
L3 = RevoluteMDH(d=0.0,       a=0.12893,    alpha=0.0,        offset=0.0)
L4 = RevoluteMDH(d=0.04039,   a=0.129,      alpha=0.0,        offset=-np.pi/2)
L5 = PrismaticMDH(theta=0.0,  a=0.0,        alpha=-np.pi/2,   offset=0.07403, qlim=[0.0, 0.04])
  
myarm = DHRobot([L1, L2, L3, L4, L5], name="My5DOF")

# 逆运动学函数-解析法
def my_ik_analytical(T_target: np.ndarray, q5_val=0.0, solution_mask=[1, -1]):

    # 机械臂参数
    d1 = 0.08525
    d4 = 0.04039
    a2 = 0.12893
    a3 = 0.129
    # L5 长度 = q5 + offset
    d5_total = q5_val + 0.07403

    # 提取位置 pos_test = np.array([x, y, z, roll, pitch, yaw])
    px, py, pz = T_target[0], T_target[1], T_target[2]
    roll, pitch, yaw = T_target[3], T_target[4], T_target[5]
    phi = 0.0
    if abs(roll) < 1e-6: # 近似为 0, 头朝上
        phi = math.pi / 2 - pitch
    elif abs(roll + math.pi) < 1e-6: # 近似为 -pi, 头朝下
        phi = pitch - math.pi / 2
    
    # 1) 计算基座 q1
    if math.sqrt(px**2 + py**2) < d4:
        print("Error: Target out of reach.")
        return None
        
    base_theta_1 = math.atan2(py, px)
    base_theta_2 = math.asin(d4 / math.sqrt(px**2 + py**2))
    q1 = base_theta_1 + base_theta_2
   
    # 2) 将末端位置投影到机械臂基座竖直平分面
    r = math.sqrt(px**2 + py**2 - d4**2)
    z_plane = pz - d1

    # 3) 求解竖直平面关节变量 q2, q3, q4
    r_wrist = r - d5_total * math.cos(phi)
    z_wrist = z_plane - d5_total * math.sin(phi)

    cos_theta3 = (a2**2 + a3**2 - r_wrist**2 - z_wrist**2) / (2 * a2 * a3)

    if abs(cos_theta3) > 1.0:
        print("Error: Target out of reach.")
        return None

    # 取上凸构型
    q3 = solution_mask[1] * (math.pi - math.acos(cos_theta3)) # 乘 -1 取上凸构型

    theta_2 = math.atan2(z_wrist, r_wrist)
    yy = a3 * math.sin(math.acos(cos_theta3))
    xx = a2 - a3 * cos_theta3
    theta_1 = math.atan2(yy, xx)
    q2 = theta_2 + theta_1
    q4 = phi - (q2 + q3)

    q2 = q2 - (math.pi / 2) # 减去 pi/2 偏置
    q = np.array([q1, q2, q3, q4, q5_val])
    return q
  
# 验证
if __name__ == "__main__":
    print("--- 逆运动学验证 ---")
    # 分别测试四组数据
    # q_test = np.array([np.radians(-0.1), np.radians(-30.6), np.radians(-42.8), np.radians(-56.1), 0.00])
    # q_test = np.array([np.radians(0), np.radians(-30.6), np.radians(-42.6), np.radians(37.5), 0.00])
    # q_test = np.array([np.radians(49.1), np.radians(-40.9), np.radians(-34.8), np.radians(-120.7), 0.00])
    q_test = np.array([np.radians(-122.7), np.radians(-38.9), np.radians(-45.0), np.radians(118.6), 0.00])
    q_test_deg = np.degrees(q_test)
    T_test = myarm.fkine(q_test)
    T_test_mat = T_test.A
    T_test_pose = (T_test_mat[0:3, 3][0], T_test_mat[0:3, 3][1], T_test_mat[0:3, 3][2])  # 提取位置部分
    T_test_euler = T_test.rpy(order='zyx', unit='deg')
    T_test_euler_rad = T_test.rpy(order='zyx', unit='rad')
    print(f"关节空间坐标(rad): {np.round(q_test, 4)}")
    print(f"关节空间坐标(deg): {np.round(np.degrees(q_test), 4)}")
    x, y, z = T_test_pose
    roll, pitch, yaw = T_test_euler_rad
    # roll 只有 0 和 pi 两种情况
    roll_deg, pitch_deg, yaw_deg = T_test_euler
    pos_test = np.array([x, y, z, roll, pitch, yaw])
    print(f"工作空间坐标(m, rad): {np.round(pos_test, 4)}")
    print(f"工作空间坐标(m, deg): {np.round(np.array([x, y, z, roll_deg, pitch_deg, yaw_deg]), 4)}")
    
    # 调用逆运动学
    q_sol = my_ik_analytical(pos_test, q5_val=q_test[4])
    if q_sol is not None:
        print(f"逆解→关节空间坐标(rad): {np.round(q_sol, 4)}")
        print(f"逆解→关节空间坐标(deg): {np.round(np.degrees(q_sol), 4)}")
```

经过验证，下面四种情况能能正确地从工作空间坐标变换回关节变量，此外，为了使机械臂都保持这种肘部上凸构型，对关节变量 $q_2,q_3$ 的范围进行了限制：$q_2 \in [0, 90°]$（示教器中未计入偏置值，因此示教器中的范围是 $q_2\in[-90°, 0]$）, $q_3 \in [-180°, 0]$
